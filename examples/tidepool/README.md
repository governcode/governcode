# Tidepool

A tiny tide-table tool, and GovernCode's demo project. It reads a day of hourly tide heights and
prints the high and low waters:

```sh
npm start          # node src/cli.js data/harbor.csv
npm test
```

It is small on purpose, with one real bug (a failing test) and one missing feature, so an AI
crew has something honest to do. [DEMO.md](DEMO.md) walks through every part of GovernCode with
it in about fifteen minutes.
