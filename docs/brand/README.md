# GovernCode brand

- `governcode-icon.svg`: the app icon (mark on the dark tile). `governcode-icon-512.png`: the same, 512 px.
- `governcode-mark.svg`: the mark alone, two colours. `governcode-mark-mono.svg`: one colour (`currentColor`).
- `social-preview.png`: 1280 x 640 share image.

The mark is a squared G whose bar reaches into a teal C: the Controller (G) and its crew (C),
each living inside the other. Colours: `#d8e0ea` (light), `#5eead4` (teal), tile `#0b0f14`.
Use the files as they are; please do not redraw, recolour or combine the mark with other logos.
