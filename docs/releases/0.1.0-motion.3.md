Third release candidate for Linux x86_64.

## Fixed

- **Toolchains installed by a version manager now run in the sandbox.** Node, npm, Python, Go
  and similar tools installed under the home folder (mise, nvm, asdf, fnm, volta, pyenv...)
  were outside the folders the sandbox allows programs to run from, so a command such as
  `npm test` failed inside the sandbox. Each such toolchain's install folder, found through
  `PATH`, is now allowed to be read and run (never written). Folders directly in the home
  folder, such as `~/.cargo`, are not granted; toolchains that resolve there (shim-based setups,
  rustup) still run from the system if installed there.
- npm's cache now lives in the run's scratch folder instead of `~/.npm`, which the sandbox does
  not let it write.

## Changed

- The README and repository description no longer describe phone-signed Gates as available;
  approvals are given in the Dashboard or the terminal, and the phone app is planned (phase 3).

## Upgrading

Run `./install.sh` from this release (with `--service` if you used it before), then restart
govd: `systemctl --user restart governcode`, or stop and start `govd`.
