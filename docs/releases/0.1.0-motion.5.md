Fifth release candidate for Linux x86_64: fewer questions, a Controller that remembers, and
plain-language requests.

The `v0.1.0-motion.4` tag has no release (its build stopped at a test that failed on timing);
everything listed here ships in this release.

## Added

- **How strict Gates are: Relaxed, Balanced (default) or Strict** (Settings › Gates, or
  `gov level`). Relaxed asks only for steps on the always-ask list and for handing work to a paid
  Runner; Balanced asks once per new kind of step and suggests remembering it for the project;
  Strict asks about everything except quiet reads and rules you made. The sandbox is the same at
  every level.
- **Compound commands are judged part by part.** `cd app && npm test 2>&1 | tail -20` counts as
  `npm test`. Anything that could hide or compute a command (substitution, subshells, background
  jobs, redirection into a file, input from a file, globs) still asks.
- **The Controller remembers the conversation** in each project: every message carries the
  recent exchange (your messages and its replies; command output is not included), as a record
  inside the message rather than as instructions. Start over
  with **New conversation** in the Dashboard or `gov reset`.
- **Personal instructions, off by default.** The first time a Controller works, GovernCode asks
  whether it should use your own instructions: for Claude Code, your CLAUDE.md, skills, agents,
  commands, plugins and hooks; for Codex, your AGENTS.md. Off, the Controller cannot read them.
  Change it in Settings › Personal instructions or with `gov personal claude|codex on|off`.
- **Plain-language delegation.** The Controller works out a Spec's brief and scope itself; the
  model may be left out, in which case the Runner uses its own default (your Settings, else the
  tool's). A Controller can throw away a Spec it proposed (`spec_discard`); accepting stays
  yours.

## Changed

- Installing packages always asks. For package managers only running the project's scripts and
  listing are kinds (`npm test`, `npm run ...`, `npm ls`); anything else asks, including install
  aliases such as `npm i` and `npm it`, and a bare `yarn`.
- Reading a git repository (`git status`, `diff`, `log`, `show`, with their plain options) is a
  kind of step like any other; other options, and git commands that change the repository or
  reach the network, always ask.
- When a Checkpoint cannot be taken for a turn, GovernCode says so in the conversation and the
  Trace.
- More programs always ask: other shells (`ksh`, `csh`...), and programs that run their input or
  another program later (`coproc`, `at`, `parallel`, `socat`, `corepack`...). A read-only program
  given an option it is not known to read with (`sort -o`, `tail -f`, `grep -f`) asks.
- A project runs one Controller turn at a time; a message sent while one is running is turned
  away with a note to wait for it to finish.
- Handing a job to a local model is a kind of step like any other; handing it to a paid Runner
  always asks.
- Listing Runners and reading a Spec's status no longer open a Gate.
- `examples/tidepool/DEMO.md` uses plain-language requests.

## Fixed

- Opening a folder that is already a project returns that project; a project name already in use
  is reported plainly.
- A test that could close the Trace while a turn was still finishing now waits for the turn.

## Upgrading

Run `./install.sh` from this release (with `--service` if you used it before), then restart
govd: `systemctl --user restart governcode`, or stop and start `govd`. Existing settings keep
their values; the new ones start at Balanced and personal instructions not yet chosen (off).
