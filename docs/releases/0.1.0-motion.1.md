The first Motion: seconded, not yet passed. It's a release candidate for people who like to
poke things, on Linux, from the terminal or the early Dashboard. Expect rough edges, and tell us
what broke.

## What's in it

- **One Controller, many Runners.** Claude Code or Codex leads your project and hands bounded
  jobs (Specs) to Runners: Codex, or a local model through Ollama. Each Runner works in its own
  copy of the project, and nothing reaches your folder until you accept it.
- **A sandbox the operating system enforces.** Landlock and seccomp, deny by default. Every run
  starts with a self-test, and if your machine can't enforce the rules, GovernCode refuses to
  start any AI tool. There's no "just this once" switch.
- **Gates.** You see exactly what will run before it runs. Allow it once, for the rest of the
  turn, or for the project. The sandbox never moves, you just stop answering the same question.
- **Checkpoints and undo.** Every change is snapshotted before and after. Undo won't overwrite
  anything you've edited since.
- **Limits.** Each provider keeps the reserve you choose, measured before and during every job.
  Local models get a machine limit instead: how many at once, how many minutes each.
- **`gov demo`**: a real task in about five minutes.

## Install (Linux x86_64)

Needs Linux 6.12 or newer (Landlock ABI 6), Node.js 22.18 or newer, git, and Claude Code or
Codex logged in.

```sh
tar xzf governcode-0.1.0-motion.1-linux-x86_64.tar.gz
cd governcode-0.1.0-motion.1-linux-x86_64
sha256sum -c ../SHA256SUMS   # if you downloaded SHA256SUMS next to it
./install.sh                 # or ./install.sh --service to start govd at login
govd &
gov demo
```

Everything installs under `~/.local` for your user; nothing needs root. `install.sh` runs the
sandbox self-test and tells you plainly if your machine can't pass it.

## Before you ship anything with it

GovernCode makes working with AI more approachable. It doesn't make you less responsible for
what you ship. Read the diff, understand the code, run the tests. The AI can write it; only you
can answer for it.
