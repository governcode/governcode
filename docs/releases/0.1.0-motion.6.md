Sixth release candidate for Linux x86_64.

## Added

- **`./install.sh --uninstall [--purge]`** removes the `governcode.service` user service, the
  `gov`, `govd` and `governcode-dashboard` links, the launcher entry and every installed release.
  It removes only what it can show is GovernCode's: releases carry a mark written at install,
  links and the launcher entry must point exactly into one of them, and anything still running
  from the install stops it before anything is removed. `--purge` also removes the Dashboard's
  settings and a state folder govd created itself (never one holding a git repository). Your
  projects are never touched.

## Changed

- `install.sh` refuses to install into an existing folder that is not the same release.
- The systemd unit is written under `$XDG_CONFIG_HOME` when it is set.

## Upgrading

Run `./install.sh` from this release (with `--service` if you used it before), then restart
govd: `systemctl --user restart governcode`, or stop and start `govd`. Releases installed by
earlier versions of `install.sh` carry no mark, so `--uninstall` lists them and leaves them for
you to remove; the same goes for a state folder that existed before this release.
