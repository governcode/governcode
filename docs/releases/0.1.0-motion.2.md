## Fixed

- **Gates now always open for Claude Code, whatever your own Claude Code settings allow.**
  GovernCode loaded your user settings (your model and preferences), and with them any
  "always allow" permission rules you had set up for everyday use. Claude Code honoured those,
  so a command like `npm test` could run without a Gate. GovernCode now sends every tool that
  acts back through its own Gates with an "ask" rule, which outranks "allow" in Claude Code;
  GovernCode's own quiet reads and standing allows still decide what really needs your answer.
  The sandbox was never affected: every step stayed inside it.

## New

- `install.sh` adds **GovernCode Dashboard** to your desktop's app launcher.
- **Tidepool**, a small demo project with a real bug and a missing feature, and a
  fifteen-minute walkthrough of every part of GovernCode: `examples/tidepool/DEMO.md`.

## Upgrade

Download this release and run `./install.sh` again (add `--service` if you used it before);
it installs next to the previous version and re-points the links. Then restart govd
(`systemctl --user restart governcode` with the service, or stop and start `govd`).
