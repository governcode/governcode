Second release candidate for Linux x86_64.

## Fixed

- **Claude Code steps now always reach GovernCode's Gates.** GovernCode loads the user's own
  Claude Code settings, including any `permissions.allow` rules, and Claude Code could run a
  command those rules allowed without asking. Every tool that acts (Bash, Edit, Write,
  MultiEdit, NotebookEdit, WebFetch, WebSearch, delegation) now carries an `ask` rule, which
  takes precedence over `allow`, so GovernCode's own rules decide: quiet reads, standing allows,
  or a Gate. Sandbox enforcement was not affected.

## Added

- `install.sh` creates a desktop launcher entry for **GovernCode Dashboard**.
- `examples/tidepool`: a small demo project with a failing test and a missing feature, and
  `DEMO.md`, a walkthrough of Gates, Checkpoints, Specs, local and Codex Runners, and Limits.

## Upgrading from 0.1.0-motion.1

Run `./install.sh` from this release (with `--service` if you used it before). It installs
alongside the previous version and updates the links. Then restart govd:
`systemctl --user restart governcode`, or stop and start `govd`.
