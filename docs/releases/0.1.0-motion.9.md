Ninth release candidate for Linux x86_64: Grok as a Runner, budgets you set, a govd on another
machine, and everything a full live test of every Runner and the Dashboard turned up.

## Added

- **Grok (xAI) as a Runner**, driven over the Agent Client Protocol. `gov connect grok` (or
  Settings › Tools) runs Grok's own device-code sign-in in a home that belongs to GovernCode; only
  a subscription sign-in counts. Every call Grok makes asks GovernCode first: reading a file,
  searching and listing a folder are quiet reads (one that reaches `/dev`, `/proc` and the like
  always asks), commands get the same checks as any other command, and every other call is a step
  named after Grok's own tool. Its Limit is Grok's own usage report, and each run's token use is
  counted. The README lists its honest limits.
- **Budgets you set** (`gov budget`, or Settings › Runners): a cap per window (5-hour, daily,
  weekly, monthly) for any cloud Runner, in tokens where the Runner reports them (Codex and Grok
  do), turns otherwise. Counted by GovernCode only, so set it below your real plan; when the
  provider reports its own usage too, the stricter one decides. Local-model caps from the
  terminal too: `gov local N M`.
- **A govd on another machine**: `gov tunnel HOST` forwards that machine's govd socket over SSH
  (key-based login only) into a folder only you can enter; `gov --host HOST ...` runs any command
  against it.
- **Answer from another terminal**: besides `gov gate`, `gov plan GP-N approve|just-you|reject`
  and `gov proposal P-N create|cancel`. `gov ask` says when a question was answered elsewhere.

## Changed

- **A Spec starts from your project as it is**, not from its last commit: your uncommitted edits
  and the files of Specs you accepted are in its copy, so you need not commit between Specs.
  Other new files you have not committed come in only if the Spec's scope names them (the Spec
  says which stayed out); files git ignores, and new files that look like secrets (`.env`, keys)
  or hold a private key, never do. A file git is told to skip or assume unchanged is copied as
  committed. The copy is read one folder at a time, never through a link, and refused over 2 GB
  or 200,000 files.
- **A finished Spec stops holding its Runner** once the provider's usage report has caught up with
  it (two hours at most); before, the unused part of its reservation stayed held until govd
  restarted.
- **Claude Code and Codex run with their run's own home as HOME**, as Antigravity and Grok did:
  no more permission error from your `~/.bashrc` on every shell step, and nothing a tool writes
  under `~` outlives the run. With your own instructions on, hooks written as `~/.claude/...`
  still work.
- **`gov ask`: a typed line answers only the question on screen.** A line typed before a question
  appeared, or within a second of it, is ignored (answer again), so a late `y` can never approve a
  Gate you have not seen. With no input (stdin closed), questions stay open for `gov gate`,
  `gov plan` or `gov proposal` instead of being denied; piping answers in no longer works.
- **Clearer CLI**: `gov help` works without govd; each command checks its arguments and says how
  to use it; unknown Runner and window names are refused instead of saved and ignored;
  `gov controller claude` works, and a Codex Controller gets Codex's own default model;
  `gov disconnect grok`; `gov trace --jsonl` exports every event; `node --version` and the like
  are quiet reads.
- A discarded Spec is listed as **discarded** (it said "undone").
- Gate, plan and proposal ids go on after govd restarts.
- **Dashboard**: the top bar and the Terminal header fit narrow windows; no "n/a" or empty
  fields; plain labels in the Trace; the Home instructions question names the tool Home runs; it
  starts from a terminal inside another Electron app (an editor, T3 Code) too.

## Fixed

- Grok's token use was not counted with Grok 1.0.46 (it moved its report), so a token budget held
  Grok at once.
- A Spec copy could not be made, and govd could hang, if a project held a FIFO where git reads its
  ignore files or config.
- A Grok Runner's words arrived one fragment per line.

## Upgrading

Run `./install.sh --service` from this release, then `systemctl --user restart governcode` (or
start `govd` yourself). Connect Grok if you want it as a Runner: `gov connect grok`. Two changes
to know: scripts that piped answers into `gov ask` should answer with `gov gate` instead, and a
Spec now sees your uncommitted work (see Changed).
